## Key Findings

- New purpose-driven descriptions + vector-only search beats v1 on MRR (0.760 vs 0.740) and R@1 (64% vs 60%).
- R@3/R@5 slightly lower than v1 (88% vs 92%) — a few cases that were R@3 in v1 are now not found at all.
- **Persistent hard failures (3 cases):** `error-state-hook`, `concurrency-limiter`, `git-diff-splitter` — embedding model cannot separate target from domain-adjacent files regardless of description quality. Needs targeted description work.
- `terminal-buffering` improved from MRR=0.00 → 0.50 — new prompt fixed the domain-context gap.
- `mcp-oauth-and-tools` still shows `.test.tsx` at R@1 — fixed in config, needs re-index to take effect.
- **BM25 lesson:** purpose-heavy descriptions are incompatible with BM25. FTS5 infrastructure retained; future use case is indexing raw code identifiers (function names, variable names) rather than descriptions.
